03 / YOUR CONTRIBUTION

Meet Quinsh.

A learnable gated activation with an explicit residual linear path. Change its parameters and observe how the output and gradient behave.

✦ DEVELOPED BY WILBERT
THE QUINSH FUNCTION
Q(x) = γ · (x − δ) · σ(w · (x − δ)) + αx
LEARNABLE / PARAMETRIC
INTERACTIVE FUNCTION PLOT

Activation output

Quinsh (editable) Swish ReLU

Illustrative function curves, mathematically generated in your browser. These are not measured training results or learned checkpoint values.

PARAMETER CONTROLS
Adjust the activation shape. These values are for exploration, not fitted Res_UCN parameters.
1.00

How strongly the gated Swish-like branch contributes.

0.00

Moves the nonlinear transition left or right.

0.10

Preserves a direct linear signal and gradient contribution.

1.00

Controls the slope of the sigmoid gate.

EXPLORE PRESETS
01

Beyond a fixed activation

The learnable shift and slope let Quinsh reshape its nonlinear response during training, rather than relying on one fixed curve.

02

A direct gradient path

The αx term supplies a residual linear contribution. It can help preserve signal flow, although it does not guarantee the absence of dead units.

03

Research origins

Inspired by Swish-style gating, parametric activations and residual learning. The formulation is described on slides 12–14 of the group presentation.

04 / COMPONENT EXPLORER

Five ideas. One system.

Explore the research rationale behind each module. Authorship is shown explicitly because the architecture was built as a team.

MODULE 01 · ACTIVATIONCONCEPT VIEW
YOUR CONTRIBUTION

Quinsh activation

Balances a Swish-like gated pathway with a residual linear branch to adapt the shape of the activation.

HOW IT WORKS

Shift the input by δ, adjust the sigmoid gate using w, scale the nonlinear branch by γ, then add αx.
